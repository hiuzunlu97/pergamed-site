| Dosya | Ne zaman |
|---|---|
| `pergamed-logo-bordo` | Açık (fildişi/beyaz) zemin, ana kullanım |
| `pergamed-logo-fildisi` | Koyu (bordo) zemin |

| `favicon` | Site sekme ikonu (küçük boyut için harf ve nokta büyütüldü) |
| `sutura-by-pergamed-acik` / `-koyu` | Sutura + "by Pergamed" birleşik logo (mağaza, site, sunum) |
